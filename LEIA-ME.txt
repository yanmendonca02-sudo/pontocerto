PONTO CERTO - como publicar na Vercel

Opcao 1 (mais facil, sem instalar nada)
1. Crie uma conta gratis em vercel.com
2. Clique em "Add New > Project" e escolha "Import" a partir de um repositorio do GitHub
   (suba esta pasta para um repositorio novo no GitHub).
3. Framework Preset: "Other". Nao precisa de Build Command nem Output Directory.
4. Clique em Deploy. Pronto: voce recebe um link https://...vercel.app

Opcao 2 (pelo terminal)
1. npm i -g vercel
2. Dentro desta pasta, rode: vercel --prod

Depois de publicado, abra o link no Chrome/Edge (ou Safari no iPhone) e use o botao
"Instalar app" no canto inferior direito.

Para conferir se esta na versao nova: o rodape mostra "v2.2".
Ao publicar uma nova versao, mude o numero em sw.js (const V="ponto-certo-v4") para v3, v4...
